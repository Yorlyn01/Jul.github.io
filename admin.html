使用说明

1. 上方表单可直接编辑网站各模块的文字内容。

2. 选择「当前语言」可切换编辑中文或英文内容。

3. 点击「保存配置」后，修改会立即生效（前台页面会自动读取）。

4. 如需编辑图片，请在「作品管理」中修改作品信息。

⚠️ 首次使用请先在 Supabase 控制台执行 SQL 创建 site_config 表（见下方）。

CREATE TABLE site_config ( id TEXT PRIMARY KEY, key TEXT NOT NULL, value TEXT NOT NULL, lang TEXT DEFAULT 'zh', page TEXT DEFAULT 'home', updated_at TIMESTAMP DEFAULT NOW() ); ALTER TABLE site_config ENABLE ROW LEVEL SECURITY; CREATE POLICY "Allow public read" ON site_config FOR SELECT USING (true); CREATE POLICY "Allow authenticated write" ON site_config FOR ALL USING (auth.role() = 'authenticated');
